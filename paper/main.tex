\section*{Abstract}
We predict which areas an active wildfire will burn the next day, using the Next Day Wildfire Spread
dataset (18\,545 patches of U.S.\ fires at 1\,km resolution), where only 1.1\% of pixels burn on day $t+1$. We
keep a per-pixel model and add 23 engineered spatial features, such as distance to the nearest fire and
fire upwind. Tuned XGBoost reaches a test PR AUC of 0.257 (95\% bootstrap interval over fire events 0.19--0.33),
compared with 0.106 for persistence. The
dataset authors report 0.225 for a random forest and 0.284 for a CNN, from a different training pipeline,
so these are reference points rather than a controlled comparison. Ablation and learning curves show that the
spatial features carry the signal: tuning changes the score by only about 0.01, and 20 times less training
data barely changes it. The model finds fire near the
existing front but misses spread beyond 5\,km. In Phase~2, a four-level U-Net trained on whole patches
with focal loss, whose 92--100\,px receptive field covers the whole patch around the fire, reaches 0.344 $\pm$ 0.007 over three seeds,
above XGBoost (0.255) and the CNN of Huot et al.\ (0.284) \pending{paired test against XGBoost on the same
fires: Priyanshu}. PR AUC rises with the context the model sees, while loss choice and data augmentation
change the score less than seed and rerun noise.

\noindent\textit{Index terms:} wildfire spread, remote sensing, gradient boosting, class imbalance,
precision-recall.
